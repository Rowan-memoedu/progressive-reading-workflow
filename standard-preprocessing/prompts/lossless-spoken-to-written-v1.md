# 信息无损口语转书面清洗合同 v1

目标不是摘要、代写或润色成另一种人格，而是让读者无需回到转写稿，也能获得全部有效信息的结构化书面正文。

优先级：

1. 原始信息与真实意图；
2. 原说话者的语言特征、立场和判断力度；
3. 结构可读性；
4. 正式、简洁、顺滑。

硬规则：

- 每个输入 source block 必须且只能映射一次，不得通过删块制造“清洗完成”。
- 保留全部实质观点、条件、例外、例子、数字、专名、术语、比较对象、结论和不确定性。
- 人物身份与关系、所在地点、时间、选择或申请所处状态、可能性判断等情境背景属于实质信息，必须保留。
- 原文逐项列举的人物、机构或原因不能擅自压成“环境不好”等泛化概括；强烈、尖锐或攻击性的措辞不得中和成温和表达。
- 缩写、网络词、圈内语、中英混用、攻击性措辞和强弱程度默认保留，不擅自中和或强化。
- 允许直接删除纯 ASR 错误、口头填充、机械重复、称呼、确认、致谢、听音检查和主持流程语。
- 对明确的纯会话词使用确定性归一：删除“我想问一下、还有别的问题吗、听得到吗、明白吗”等流程语和无语义的“嗯、呃”，并压缩“然后然后、这个这个”等机械重复；该步骤不得删除实质背景、身份、观点或结论。
- 把相邻问答、插话和字幕碎片合并为语义完整的书面段落；问题中的有效背景必须进入正文，不能连同问句一起丢失。
- 书面正文不保留“一问一答”的转写外观，不出现无意义的“明白吗／明白／对吧／你懂吗／我想问一下／还有问题吗”等会话操作。
- 保持原说话者直接陈述的视角；不得改成“作者认为、说话者指出”等第三人称转述稿。
- 只可新增不携带新判断的导航标题。不得新增外部事实、解释、建议、论据或结论。
- 不得把原文案例推导成原文没有明说的通用原则；即使推断看似合理，也不能进入清洗正文。
- 明显同音字或断句错误可以修正；不确定的人名、机构、术语和事实保留原状，不靠模型记忆补全。
- 代码、伪代码、URL、LaTeX、行内代码和审查占位符必须原样保留。
- 清洗后正文应与原文信息体量相当；不能用更短的概览替代全文。

审计要求：

- 每个输出章节列出按原顺序覆盖的 source_block_keys。
- 结构化、合并或语气规整过的原句由本地 artifacts 保存，最终阅读 Markdown 只呈现清洗后的正文。
- 本地校验器负责覆盖、顺序、长度、保真、受保护语法、可见时间码、会话噪声和确定性锚点；校验失败时必须按错误重试，不得降格冒充通过。
