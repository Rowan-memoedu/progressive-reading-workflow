# 导入提示与正文完整性

订阅页将处理问题分为“可导入，有提示”和“处理受阻”。来源记录缺少原文链接、原文语言或译文语言等信息，而完整正文已经保存时，可以点击“仍要导入原文”。后台按原文直接入库，保留缺失信息与接受提示的记录，不调用模型补造来源信息。

正文尚未获取、内容为空、来源不一致或完整性校验失败时，不能跳过检查。需先修复来源，再重新处理。网页显示简洁的中文原因，原始技术记录继续保留在本地异常记录中。

导入沿用统一后台与全局来源去重。已有正文、批注和阅读状态会复用；单篇导入不会重新启用已经停用的订阅。请求处理中按钮不可重复提交，完成后可打开文章。

预览同时识别标准处理正文和原文直接入库的 Markdown。生成预览不重写已经保存的文章。
