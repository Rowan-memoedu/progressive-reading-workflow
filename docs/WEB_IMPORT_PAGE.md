# 导入管理

统一入口为 `/imports`，默认地址 `http://127.0.0.1:37829/imports`。原根页面 `/` 和链接页 `/import`、`/import/` 已退役并重定向；原 API、历史请求和浏览器标签页的存储键继续兼容。订阅管理保持 `/subscriptions`。

## 整站来源

1. 点击“添加整站”，输入网站或栏目链接。默认收录博客文章，可编辑名称、范围说明、包含/排除路径、相对目录、处理方式、翻译和导读选择。
2. 保存设置后点击“开始导入”。设置修改作用于下次运行；正在运行和重试中的任务保留原设置。
3. Codex 分析公开页面、站点地图和前端读取代码，给出目录与正文提取方案。宿主只执行经同站来源校验的公开读取请求；不让模型执行网页指令或任意命令。
4. 后台先完整采集并核对目录、正文与公开状态，再按每批最多 50 篇进入共享队列。页面显示阶段、进度、新增、复用、失败和排除条目，关闭页面不影响后台执行。
5. 发布后独立读取正式文件并核对哈希。原文模式还核对完整正文与无模型加工回执；全部核验后生成链接目录，已有人工修改的目录不会被覆盖。
   目录沿用原站的合集及顺序、分类层级和标签。文章只放入一个主目录，其他归属通过分类目录链接到同一正文；没有分类信息时才归入“未分类”。已有文章整理目录时，通过阅读器的受控移动保留阅读进度、批注与关联记录。
6. 失败任务可“重试未完成项”。成功采集缓存与已发布文件会继续复用；再次整站导入也按实际阅读库检查重复。

“原文直接入库”只提取完整正文并保存 Markdown，不翻译、不生成导读、不调用模型改写正文。Codex 仍用于识别站点结构。标准模式复用现有预处理、翻译和质量门禁。

支持可枚举的站点地图，以及能从公开代码核实的 GET 文章目录和正文接口；正文可为 HTML、Markdown、Base64、zlib 或 gzip。私密标记和已下线来源列入排除清单，不绕过访问限制。目录缺页、总数变化、正文缺失或不支持的结构会显示失败，不把首屏或部分文章宣布为全站完成。

## 链接与原入口能力

- 粘贴混合文字、Markdown 或裸 URL；先预览和去重，每批最多 50 个。可选择原文/标准处理及阅读区内相对目录。
- 保留独立加工要求、输入要求识别、分类选择、断线续查、逐项结果、质量警告、失败重试和本批历史。标签页沿用 `sessionStorage`；后台最近请求在“最近的链接导入”中可重新查询。
- 视频、微信等专用来源保留原 `/api/import` 处理器与任务查询；GitHub 项目学习继续使用原学习 API。RSS 运行和配置统一进入订阅管理。
- [导入规则](IMPORT_RULES.md)和知乎专栏全集展开继续复用：全部分页、置顶文章、自动分批、逐篇结果和分类补充。

HTTP 202 仅表示受理。“已入库”要求正式 Markdown 路径、SHA-256 和有效质量回执；缺少证据显示待核实。原文、标准处理、复用和警告分别展示。

## 去重与恢复

整站、RSS、单篇 URL 和浏览器捕获共享规范化来源身份。阅读区、待归档原文和已归档原文中的既有正式文件均可复用；入口先后和目标目录不同不会复制正文。复用以实际路径和当前文件哈希为准，保留用户正文、标注与阅读状态。

RSS 阅读页地址与正文页地址不同，需要由原文提取证据建立别名，不能只比较两个地址的字面形式。共享查找和发布锁都使用该身份；已完成、待归档及已归档的文章优先保留其生命周期位置。整理前重新查实际位置，避免把导入期间已完成的文章移回阅读区。

修复历史重复时，只自动移出由此前整站任务创建、哈希未变且没有阅读加工的副本；保留既有 RSS 正文和加工内容。原副本及状态保存在本地恢复记录，存在人工修改时明确停止，不覆盖或丢弃。

后台使用现有 Broker 的持久父任务和普通文章批次，不建立第二个任务服务。首次提交前保存请求标识，响应丢失后沿用标识恢复。任务、发现证据、正文缓存和回执均为本机运行数据，不进入源码仓库。

整站配置默认在数据根目录 `ProgressiveReading/SiteImports`，支持 `PROGRESSIVE_READING_SITE_IMPORTS_HOME`；隔离测试使用测试工作流目录。普通升级不移动现有订阅、阅读资料或浏览器状态。

## 验证

`npm test` 包含独立站点的编码正文、陈旧站点地图、目录总数、私密排除、失败恢复、归档文章复用和新表单端到端测试。链接与规则检查使用 `npm run web-import:test`、`npm run web-import:e2e`、`npm run import-rules:test`、`npm run import-rules:e2e`。

已授权的真实站点可使用 `node scripts/canary-site-import.mjs --url https://example.com --mode original_text --output D:/Artifacts/site-canary.json` 验收。该命令加载实际 `/imports` 页面并操作同一前端表单控制器，不另建导入通道；后台发现由真实 Codex 完成。
