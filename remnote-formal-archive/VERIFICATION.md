# 正式归档验证边界

运行 `npm run remnote:archive:check` 检查包 schema、幂等计划、精确目标、内容边界、零内容确认、回执与恢复行为。测试使用隔离合成材料，不写入真实 RemNote。

真实验收应依次检查：宿主生成 native-v2 包、dry-run、用户明确选择的目标、写入与逐项回读、receipt、插件/sidecar 最终状态和原文位置。

当前发布仍保留宿主真实确认弹窗和 receipt 到插件的最终状态同步边界。生成包、通过离线测试或仅有旧归档标签均不足以证明端到端正式归档已上线。

历史私人材料、目标节点、会话和运行回执不随源码发布。真实验收记录应保存在调用者的本机产物目录。
